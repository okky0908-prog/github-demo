# モックアップ実装計画書：Trello風タスク管理アプリ

## Context

[画面仕様・画面遷移・ユースケース](./screens.md)、[機能要件](./features.md) を定義済みの段階で、本実装（React/バックエンド等）に着手する前に画面イメージを目視で認識合わせしたく、バックエンド・ビルドツール・フレームワーク一切なしの静的HTML/CSS/JSでブラウザ上に動くモックを作成した。データはメモリ上のみで保持し、リロードで消える想定（DB永続化は対象外・本実装で対応）。

配置場所は `mockup/`（リポジトリ直下、`docs/`とは独立）。ドラッグ&ドロップはHTML5標準のDrag and Drop APIで実際に動く形にした。

## 作成ファイル

- `mockup/index.html` — ページ骨格（ヘッダー、リスト列のコンテナ、カード編集モーダル）
- `mockup/style.css` — 見た目（Trello風のカラム型レイアウト、カード、優先度カラーラベル、モーダル、ドラッグ中のスタイル）
- `mockup/script.js` — 画面ロジック（メモリ上のデータモデル、描画、各種操作、DnD）

## データモデル（script.js内、メモリのみ）

```js
let lists = [
  { id, title, cards: [ { id, title, description, priority, dueDate }, ... ] },
  ...
];
```

初期データとして [画面仕様](./screens.md) にある初期リスト例（未着手／進行中／完了）と、優先度・期限のあるカードを2〜3件ずつ仕込み、表示イメージが一目でわかるようにした。

## 実装した機能（画面仕様・機能要件との対応）

| 画面仕様の項目 | モックでの実装 |
|---|---|
| 画面構成（SPA・単一画面） | index.html 1枚のみ、画面遷移なし |
| ボード画面 | ヘッダー＋横並びリスト列＋末尾に「＋リストを追加」 |
| リスト操作UI | リスト名はクリックでインライン編集（input化）／「…」メニューから削除（確認ダイアログ経由） |
| カードの表示 | タイトル、優先度カラーラベル（高:赤/中:黄/低:青系）、期限日表示 |
| カード作成・編集 | リスト下部「＋カードを追加」でタイトルのみ簡易作成／カードクリックでモーダルを開き全項目編集・保存 |
| カード削除 | モーダル内削除ボタン＋確認ダイアログ |
| 画面遷移 | ボード画面⇔カード編集モーダルの開閉のみ、ページ遷移なし |
| UC-01〜08 | すべてモック上で動作するように実装（リスト作成/改名/削除、カード作成/編集/削除、リスト間DnD移動、同一リスト内並び替え） |
| UC-09（再訪問時にDB取得） | 対象外（バックエンドなしのため）。モック画面上部に「このモックはブラウザを閉じると内容がリセットされます」旨を注記 |

## ドラッグ&ドロップ

- カード要素に `draggable="true"` を付与
- `dragstart` でドラッグ中カードIDを保持、`dragover`（`preventDefault`）でドロップ可否とプレースホルダー表示、`drop`でデータモデルの`lists`配列を更新（リスト間移動・同一リスト内並び替えの両方に対応）してから再描画
- ライブラリは使わず素のAPIのみで完結（本実装ではdnd-kitを使う想定だが、モックでは不要）

## 見た目・スタイル方針

- [非機能要件](./non-functional-requirements.md) の互換性要件（Chrome最新版・画面幅1280px以上のPC想定）に合わせ、レスポンシブ対応は最小限
- Trelloライクな配色（ライトグレー背景・白いカード・カラム型レイアウト）
- 優先度ラベルは色分けチップで表現

## 動作確認方法

- `mockup/index.html` をブラウザ（Chrome）で直接開く（`file://` パス）、またはmockupディレクトリで `python3 -m http.server` を起動してlocalhost経由で開く
- 確認項目：
  - リストの作成／インライン名称変更／削除（確認ダイアログ）
  - カードの簡易作成／モーダルでの編集（タイトル・説明・優先度・期限）・保存／削除（確認ダイアログ）
  - カードのドラッグでのリスト間移動・同一リスト内並び替え
  - 優先度カラーラベル・期限表示が仕様通りに出るか
  - ページリロードでデータがリセットされる（想定通りの挙動）

## 動作確認結果

Playwrightによるブラウザ自動操作で以下を確認済み（コンソールエラー0件）。

- リスト名のインライン編集
- リスト追加
- カード簡易作成（タイトルのみ）
- カードクリック→編集モーダル→優先度等を保存
- カード削除（確認ダイアログ）
- カードのドラッグ&ドロップでのリスト間移動（優先度・期限を保持したまま移動）
